Entry for [Famous Last Words: The Funniest Epitaph](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406) ($2) on make.fun.

`main.py` (pure Python 3.13 standard library, deterministic, no network) writes one funny one-line epitaph to `/output/entry.txt` and prints it:

> I spent my life hitting 'remind me later.' Death was the one update that couldn't be postponed.

Run it with:

```sh
python3 main.py
```
